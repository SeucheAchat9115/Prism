# Code of conduct

Be respectful, constructive and welcoming. Discuss ideas and code rather than
attacking people. Harassment, discriminatory language, threats, sexual harassment,
publication of private information and repeated disruptive behavior are unacceptable.
These expectations apply to project issues, reviews and other project spaces.

The lead maintainer may edit or remove inappropriate content, lock discussions,
warn participants, or temporarily or permanently restrict participation. Responses
should reflect the severity and repetition of the behavior. Good-faith disagreement
and respectful criticism are welcome.

For visible abuse, use GitHub's Report content feature. Do not publish sensitive
personal details in an issue. For a private report, use a private contact channel
explicitly published by @SeucheAchat9115 on their GitHub profile, if available;
otherwise use GitHub reporting. Security advisories are for software vulnerabilities.
Reports about the maintainer can be made directly to GitHub. Do not retaliate against
people who report concerns in good faith.
