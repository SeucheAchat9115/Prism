# Prism

Prism is a script-first Python music production toolkit. A song is described in
one readable Python file using MIDI, samples, native instruments, effects,
automation, and mixing, then rendered reproducibly as WAV and MIDI files.

Prism is designed to keep music projects understandable, editable, and easy to
recreate without requiring producers to build an application around them.
