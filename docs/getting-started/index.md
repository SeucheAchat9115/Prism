# Getting started

Prism projects are ordinary folders. Each project contains a readable song
script, optional audio files, and generated renders:

```text
projects/
└── my-song-20260828-143500/
    ├── main.py
    ├── sounds/
    └── renders/
        ├── song.wav
        └── song.mid
```

Start here in order:

1. [Install and prepare Prism](installation.md).
2. [Create and render your first song](first-song.md).
3. [Understand the project folder](project-folders.md).
4. Continue with the [step-by-step tutorials](../tutorial/README.md).

All commands in this documentation run from the Prism repository root on both
Windows and Linux. You never need to change into the generated project folder.
